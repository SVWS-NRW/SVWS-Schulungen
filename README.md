# SVWS-Schulungen

Schulungsdokumentation für die fünf Regierungsbezirke in NRW. Die Rubrik Arnsberg enthält die Schulungsmodule und Moderationsartikel aus [FBM](https://github.com/Raffenberg/SVWS_FBM/tree/4a8c4c16bb45805c9339e5bf497bb3412d10fe85). Die übrigen Bezirke haben einen vorbereiteten Einstieg.

## Lokal starten

Mit Node.js 24 im Repository zuerst npm ci und dann npm run docs:dev ausführen. npm run docs:check prüft Navigation, Markdown, Build und lokale Links. Für GitHub Pages ist als Quelle GitHub Actions vorgesehen. Der Veröffentlichungsworkflow startet bei Änderungen an master.
