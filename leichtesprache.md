# Leichte Sprache

## Worum geht es auf dieser Internet-Seite?

Auf dieser Internet-Seite finden Sie Unterlagen für Schulungen.
In einer Schulung lernen Sie, wie Sie mit SchILD-NRW und SVWS arbeiten.
Oben im Menü stehen die Regierungs-Bezirke. Wählen Sie den passenden Bezirk.

## Wie finde ich eine Anleitung?

Oben auf der Seite gibt es ein Menü.\
In dem Menü stehen verschiedene Themen.\
Wählen Sie ein Thema aus.

Oben gibt es auch eine Suche.\
Wählen Sie **Suchen**.\
Schreiben Sie ein Wort in das Such-Feld.\
Zum Beispiel **Zeugnis**.\
Dann können Sie eine passende Anleitung öffnen.

## Wo bekomme ich Hilfe?

Haben Sie eine Frage zum Computer-Programm?\
Dann können Sie eine Fach-Beratung fragen.\
Die Menschen in der Fach-Beratung kennen das Programm gut.

[Eine Fach-Beratung finden](https://www.svws.nrw.de/service/fachberatersuche)

Haben Sie ein Problem mit dieser Internet-Seite?\
Dann können Sie uns eine E-Mail schreiben.

[E-Mail an die Redaktion](mailto:webmaster@svws-nrw.de)
